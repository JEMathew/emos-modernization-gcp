# Learn EMOS

> **Public EMOS Beta v1.0 learning center**  
> Explore the product journey without signing in to EMOS.

[![EMOS Learning Center](learning/emos-learning-background.png)](https://drive.google.com/drive/folders/1ONwIDuVpKqu3DJzmHgzrtYTeJaOUXqQ1?usp=drive_link)

[Launch EMOS](https://emos-modernization.ai.studio) · [Open the complete video library](https://drive.google.com/drive/folders/1ONwIDuVpKqu3DJzmHgzrtYTeJaOUXqQ1?usp=drive_link) · [Return to the project README](../README.md)

The Google Drive folder is the canonical video library for this beta. Open the library and select the filename shown beneath each lesson. The videos contain demonstration data only; never record or upload customer information, credentials, tokens, or production secrets.

## Recommended learning path

For a concise end-to-end view, watch the introduction followed by **F10 → F11 → F12 → F03 → F04 → F19**. This sequence moves from portfolio discovery through Enterprise DNA, explainable 6R decisions, wave planning, and mobilization readiness.

## Beta scope note

The videos document capabilities available in EMOS Beta v1.0. Automated live CMDB discovery, organization-wide RBAC, disposition-specific execution agents, autonomous validation, benefit-realization tracking, and marketplace distribution remain future scope unless explicitly identified otherwise.
